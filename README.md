### 🚀 Proyek Unggulan

Berikut adalah beberapa proyek backend, API, dan AI yang sedang dan telah saya kembangkan:

* 🤖 **ai-agent** `Dalam Pengembangan`
  * Agen AI *coder* adaptif yang dirancang khusus untuk berjalan di lingkungan **Termux**. Membantu proses pengembangan kode langsung dari terminal perangkat seluler.
